# Waniyah Khan — Copywriter Portfolio

Responsive static portfolio made with HTML, CSS and vanilla JavaScript.

## Preview
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to Vercel
1. Upload the contents of this folder to a new GitHub repository.
2. Import that repository into Vercel.
3. Select **Other** as the framework preset, leave build command blank, and use `.` as the output directory.
4. Deploy.

## Before publishing
- Replace `hello@waniyahkhan.com` in `index.html` with your preferred email.
- Confirm the three Google Docs are set to “Anyone with the link can view.”
- Test on mobile and desktop.
- These are speculative concept projects, not commissioned client work.
